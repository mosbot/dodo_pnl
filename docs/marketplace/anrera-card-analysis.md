# Разбор карточек Anrera Tech на маркетплейсе (2026-09-04)

Источник: `/privateapi/web/v1/applications/pages/{id}` (публичный контент
карточки) и слайды с CDN. Приложения: Будильники (854 установки), Тесто (387),
Соревнования (209), Выдача (20), Генератор знаков (31).

## Слайдер

- Размер **1280×817 = ровно пропорция бокса карусели** (1817/1160). Они
  знают формат — ничего не сжимается.
- **Кадр 1 — обложка без скриншота**: фирменный красный «блоб»-градиент на
  белом, заголовок в 3 строки крупным гротеском (обещание: «Комплексное
  решение по контролю пищевой безопасности», «До 40% быстрее скорость
  выдачи»*), под ним **4 «пилюли» 2×2** с выгодами по 5–8 слов, справа
  вверху — иконка приложения. Ни логотипа-слова, ни адреса.
- **Кадры 2–5 — заголовок в 1–2 строки + крупный фрагмент интерфейса**, не
  весь экран: одна панель/модалка, обрезанная так, что текст в ней читается
  при ширине 520 px. Тот же блоб-фон, без «браузерной рамки».
- Сноска мелким текстом, если в заголовке цифра («*на основе данных…»).

## Описание («О приложении»)

- Первый абзац: **жирное название продукта** + одно предложение «что это»,
  дальше 2–3 предложения контекста (400 знаков).
- Заголовок H4 «Возможности приложения» → маркированный список 5–8 пунктов.
- Далее по фиче: H4 → абзац → **картинка прямо в тексте** (блок `image`,
  медиа-id — Editor.js image tool в кабинете).
- **FAQ-заголовки как возражения**: «Как повлияет озвучка на гостей?»,
  «Почему по номерам, а не именам?», «Влияние на проверки», «Опыт
  тестирования» (соц. доказательство).
- Блоки **alert** (info) для важных оговорок (требования к устройствам,
  что приложение не делает).

## Инструкция

- «Шаг 1. Авторизация» → нумерованный список; «Шаг 2. …» → абзацы +
  скриншоты; alert про поддерживаемые браузеры/устройства; нумерация
  списка может продолжаться (`start: 3`) после картинки.

## Мета

- Категорий **4** (Уведомления, Менеджмент, Списания, Сырье) — значит наш
  отказ «Менеджмент» был из-за лимита 4, а не запрета; у Кассы сейчас 2.
- Языки ru+en, концепции Додо+Дринкит, «все страны» — шире охват в каталоге.
- Поддержка — Telegram-бот клиентов, не личный чат.

## Что берём для «Dodotool Касса»

1. Слайды: обложка с 4 пилюлями + 4 фичевых кадра с **фрагментами** экрана
   (модалка закрытия смены, панель курьеров, история операции, журнал
   сверху), оливковый блоб-фон в палитре Кассы, иконка справа вверху.
2. Описание: жирное имя в лиде; «Возможности» списком; картинки внутри
   разделов; 2–3 FAQ-заголовка («Что видит менеджер, а что владелец?»,
   «Что если ошиблись в операции?», «Пишет ли Касса что-то в Dodo IS?»);
   alert «Касса только читает Dodo IS».
3. Инструкция шагами с картинками и alert про браузер/устройство.
4. Категории: добавить «Менеджмент» (лимит 4).
