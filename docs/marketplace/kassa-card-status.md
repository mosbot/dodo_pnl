**Как грузить картинки в описание** (Editor.js image-блок):
`POST /privateapi/web/v1/manage/products/pages/content/media` с JSON
`{applicationPageId, alias:'description'|'sliders'}` → `{url,id}`; затем
`PUT url` с FormData `file`; блок `{type:'image',data:{id}}`. Alert-блок:
`{type:'alert',data:{type:'info',align:'left',message}}`.
