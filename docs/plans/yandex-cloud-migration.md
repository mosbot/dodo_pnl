## Варианты

### A. Lift-and-shift: одна ВМ, всё в Docker как сейчас

| A1. 2×50 % Ice Lake, 4 ГБ, 40 ГБ HDD | 1 080 | 950 | 138 | 190 | **≈2 360 ₽** |
| A2. 2×50 %, 4 ГБ, 40 ГБ SSD | 1 080 | 950 | 573 | 190 | ≈2 790 ₽ |
| A3. 2×100 %, 8 ГБ, 40 ГБ SSD | 1 786 | 1 901 | 573 | 190 | ≈4 450 ₽ |
| A4. 4×50 %, 8 ГБ, 60 ГБ SSD | 2 160 | 1 901 | 860 | 190 | ≈5 110 ₽ |

Для нашей нагрузки честный аналог текущего сервера — A2/A3. Полезное
сверх VPS: снимки диска (30 ГБ ≈ 110 ₽/мес за точку), смена размера ВМ за
минуту, приватная сеть, бесплатные 100 ГБ трафика. Никаких изменений в
коде и compose — только перенос `.env`, volumes и DNS.

| ВМ 2×50 %, 4 ГБ, 30 ГБ HDD, IP | 1 080 + 950 + 104 + 190 | ≈2 320 ₽ |

| **Итого** | | **≈5 660 ₽** |

С CVoS на год по БД (100 % vCPU классы) — минус ~20 % на БД. HA-кластер
из 3 хостов ≈ 10 000 ₽ только за БД — нам не нужен.

Что даёт Managed PostgreSQL: автоматические ежедневные бэкапы + **PITR по
WAL из коробки** (7 дней по умолчанию, бесплатно в пределах размера
диска), обновления версий, мониторинг, реплика по кнопке. Это закрывает
пункт «WAL-архив» без нашей работы. Минус: Redis остаётся на ВМ (Managed
Valkey — ещё ~2 000 ₽/мес за минимальный класс, не стоит того).

### C. Только WAL-архив в Object Storage, без миграции — рекомендуемый первый шаг

Ставим на текущий VPS `wal-g` (или `pgbackrest`) в контейнер Postgres,
`archive_mode=on`, `archive_command='wal-g wal-push %p'`, базовый бэкап
раз в сутки (`wal-g backup-push`), ретенция 14 дней. Object Storage — S3-
совместимый, отдельный сервисный аккаунт со статическим ключом только на
один bucket.

Объёмы: базовый бэкап ~100 МБ (сжатый ~30 МБ) × 14 = 0,5 ГБ; WAL при нашей
записи — единицы ГБ/мес даже с `archive_timeout=300` (пустые сегменты
жмутся почти в ноль); итого ≤ 10 ГБ хранения.

| Статья | Расчёт | /мес |
|---|---|---|
| Хранение 10 ГБ, стандартное | (10 − 1) × 2,38 | ≈21 ₽ |
| PUT ~9 000/мес (WAL каждые 5 мин) | первые 10 тыс. бесплатно | 0 ₽ |
| Исходящий (только при восстановлении) | в пределах 100 ГБ | 0 ₽ |
| **Итого** | | **≈20–50 ₽/мес** |

RPO падает с 4 ч до ≤ 5 мин, restore — `wal-g backup-fetch` + replay на
любой хост (в т.ч. на новую ВМ в Yandex Cloud — это же и есть путь миграции
БД). Работа: ~2 ч (образ postgres с wal-g, конфиг, проверка restore на
staging-БД).

### WAF (Smart Web Security)

Требует пропускать трафик через Yandex Application Load Balancer (свой
тариф, ~1 500–2 000 ₽/мес за минимальный) + прокси-единица SWS ≈ 1 757
₽/мес + запросы: при нашем ~0,3–1 млн запросов/мес первая ступень стоит
до **27 450 ₽/мес** — пропорционально объёму, т.е. ~8–27 тыс. ₽. Для
B2B-сервиса с входом только через Dodo IS это несоразмерно; Caddy +
rate-limit + fail-closed enforcement закрывают наш профиль риска. Не
рекомендую. DDoS-фильтрация на публичный IP (2,26 ₽/ГБ входящего) — при
нашем трафике десятки рублей, можно включить при миграции.
